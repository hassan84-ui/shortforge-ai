# ShortForge AI Mobile

Expo mobile shell for iOS and Android using the live ShortForge production app.

## Run
1. Install Node.js 20+.
2. From this folder run `npm install`.
3. Run `npx expo start`.
4. Open with an Android/iOS development build.

## Store release
Configure Apple/Google developer accounts and signing, add final app icons/splash assets, test camera/media/export behavior on physical devices, and review digital-subscription purchase flow against current App Store and Play billing rules before submission.

The production web app remains the source of truth, so existing accounts, projects, AI generation, voice, stock media, and export remain available.
